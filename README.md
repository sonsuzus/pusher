# Flarum Pusher Entegrasyonu

Bu eklenti, Flarum tabanlı topluluklar için gerçek zamanlı (real-time) iletişim altyapısı sağlar. 

Varsayılan Pusher API'sini simüle ederek; bildirimlerin, yeni mesajların ve anlık güncellemelerin sayfayı yenilemeden kullanıcılara iletilmesini mümkün kılar. Dışa bağımlı ve maliyetli servisler yerine, kendi sunucunuzda barındırdığınız (self-hosted) **Soketi** gibi açık kaynaklı WebSocket sunucularıyla tam uyumlu çalışacak şekilde tasarlanmıştır.

## Temel Özellikler
* Gerçek zamanlı tartışma güncellemeleri ve anlık bildirimler.
* Kendi barındırdığınız WebSocket (Soketi) sunucuları ile uçtan uca uyumluluk.
* Düşük gecikme süresi.
